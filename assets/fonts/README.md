# Font assets

Font files are organized by the font families used in the app and are
registered in `pubspec.yaml`:

- `GeneralSans/`
- `Inter/`
- `Nunito/`
- `NunitoSans/`
- `PlusJakartaSans/`
- `Roboto/`

Place additional `.ttf` or `.otf` files in the matching family folder and add
their asset paths to that family's `fonts` list in `pubspec.yaml`.
